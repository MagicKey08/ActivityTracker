# Changelog

## 1.0.1 (2026-10-31)

- Compatibility with Vencord 1.15.15 and newer (Discord ~4.29): switched to the new Button component and replaced the removed Forms.FormTitle. No feature changes.

## 1.0.0 (2026-10-25)

First release.

- Voice session, activity, status, profile, message and typing tracking for users you choose
- Dashboard with profile card, voice time by server, weekly heatmap and timeline
- Logs stored as per-user files in the Vencord data folder, with configurable retention
- Message logging is off by default
